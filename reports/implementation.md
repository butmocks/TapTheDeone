# Отчёт: Tap The Drone (Flappy‑like)

## Причина “не работает”

В `index.html` был подключён скрипт `game.js`, но файла не существовало. В результате браузер не запускал игровую логику.

Дополнительно: чтобы исключить проблему кеширования (особенно на статических хостингах), подключение `style.css` и `game.js` сделано с query‑параметром версии (`?v=20260107`).

## Что сделано

- Реализован `game.js` (Canvas 2D):
  - игровой цикл `requestAnimationFrame`, стабильная физика (ограничение dt)
  - “флап” по клику/тапу/`Space`/`W`/`↑`
  - генерация препятствий с окнами, счёт за успешное прохождение
  - столкновения (препятствия/потолок/пол), экран поражения
  - пауза `P`, рестарт `R`, меню `Esc`
- Добавлены уровни (сложность + визуальный стиль), выбираются на старте:
  - **Город (легко)**: медленнее, окно шире
  - **Пустыня (норм)**: быстрее, окно уже
  - **Арктика (хард)**: самый быстрый, самое узкое окно
- Рекорд хранится в `localStorage` отдельно на каждый уровень.
- Опциональный звук (кнопка “Звук: вкл/выкл”) на WebAudio.

## Как запускать

Рекомендуется через локальный сервер:

```bash
cd /workspace
python3 -m http.server 8000
```

Открыть `http://localhost:8000`.
