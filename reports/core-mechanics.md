# Отчёт: основа механик FPV Bomber (вид сверху)

## Что реализовано

- **Вид сверху (top-down)**: карта больше экрана, камера следует за дроном.
- **Управление дроном**: WASD/стрелки, инерция/затухание скорости, ограничение максимальной скорости.
- **Сброс боеприпаса по таймингу**: по нажатию `Space` создаётся «бомба» с фитилём (по умолчанию ~0.45с). Взрыв происходит **в точке сброса**, поэтому при движении нужно сбрасывать заранее/вовремя.
- **Урон по радиусу**: при взрыве уничтожаются цели в радиусе, начисляются очки согласно таблице.
- **Боезапас и перезарядка**:
  - ограниченное число боеприпасов (`maxAmmo`)
  - перезарядка занимает время (`reloadTime`), на период перезарядки сброс запрещён
  - перезарядку можно стартовать вручную (`R`) или она стартует автоматически при опустошении боезапаса
- **Апгрейды за очки**: магазин (`Tab`) позволяет покупать улучшения:
  - скорость
  - ускорение перезарядки (уменьшение времени)
  - радиус урона
  - ёмкость боезапаса

## Таблица начисления очей

В прототипе используется таблица:

1. Чмоня — **10**
2. Палатка — **20**
3. Боеприпасы — **50**
4. Техника — **100**

Она же отображается в UI справа и задаёт поведение начисления.

## Где менять баланс

- `src/main.js`:
  - `SCORE_TABLE` — типы целей, очки, цвет/размер
  - `BASE` — базовые параметры (скорость, фитиль, радиус, перезарядка, боезапас)
  - `SHOP` — апгрейды, цены, множители стоимости, максимальные уровни
