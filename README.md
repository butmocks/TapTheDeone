# Tap The Drone

Небольшая 2D игра в браузере (Canvas) в стиле Flappy Bird: дрон “ЗСУ” летит слева направо, а игрок кликом/тапом или клавишей даёт импульс вверх, чтобы пролетать в окна между препятствиями.

## Запуск

Откройте `index.html` через локальный сервер (так надёжнее, чем double‑click):

```bash
cd /workspace
python3 -m http.server 8000
```

Затем откройте в браузере `http://localhost:8000`.

## Управление

- **Клик/тап / Space / W / ↑**: импульс вверх
- **P**: пауза
- **R**: рестарт
- **Esc**: в меню

## Уровни

На старте можно выбрать уровень (сложность + стиль):

- **Город (легко)**: шире окна, медленнее скорость
- **Пустыня (норм)**: быстрее и окна уже
- **Арктика (хард)**: ещё быстрее и самые узкие окна

Рекорд хранится отдельно для каждого уровня (LocalStorage).
