# FPV Bomber (вид сверху) — прототип

Минимальная «основа» игры: мы управляем FPV-бомбером в виде сверху, пролетаем над целями и сбрасываем боеприпас **вовремя** (взрыв происходит через небольшой фитиль). Боезапас ограничен, **перезарядка занимает время**, а заработанные очки можно тратить на **апгрейды**.

## Запуск

Проще всего запустить через локальный HTTP-сервер:

```bash
cd /workspace
python3 -m http.server 8000
```

Открой в браузере `http://localhost:8000`.

Можно и просто открыть `index.html`, но в некоторых браузерах есть ограничения для локальных файлов.

## Управление

- **WASD / Стрелки**: движение
- **Space**: сброс боеприпаса
- **R**: начать перезарядку (если боезапас не полный)
- **Tab**: открыть/закрыть магазин апгрейдов

## Таблица заработка очей

В UI справа есть таблица начисления, по умолчанию:

1. Чмоня — 10
2. Палатка — 20
3. Боеприпасы — 50
4. Техника — 100

## Файлы

- `index.html` — страница + UI
- `src/main.js` — логика (движение, бомбы, перезарядка, очки, апгрейды)
- `src/style.css` — стили
- `reports/` — отчёты/заметки по проекту
